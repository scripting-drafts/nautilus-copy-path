# Nautilus Copy Path

Adds **Copy Path** / **Copy Paths** to the Nautilus right-click menu.
The extension is overlaid through a user-level Bubblewrap mount, so it needs
no root install or system package. Desktop-icon Copy Path lives in
[ding-image-drag](https://github.com/scripting-drafts/ding-image-drag).

Install: `./install.sh` · Uninstall: `./uninstall.sh` · Rebuild: `./build.sh`
Re-run `./install.sh` after reinstalling the patched Nautilus binary.
